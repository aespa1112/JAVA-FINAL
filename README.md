
## 台灣法規與適用範圍聲明（重要）

本系統為 **教學／內部記帳原型**，用於示範複式簿記、傳票流程、職責分離與審計軌跡，
**不構成**可交付執業會計師或記帳士對外申報使用的完整合規產品。

### 適用範圍（設計目標）
- 對象：非公開發行公司、獨資、合夥之 **教學模擬**
- 參考規範：《商業會計法》、《商業會計處理準則》、《企業會計準則公報（EAS）》
- **不適用**：公開發行公司應採用之金管會認可 IFRSs

### 會計基礎
- 入帳介面可記錄應收／應付等權責項目
- **尚未實作** 系統化決算調整分錄（折舊、攤銷、期末調整精靈）
- 資產負債表「保留盈餘／本期損益」為 **報表層計算呈現**，非自動產生結帳分錄

### 憑證與保存
- 記帳憑證含日期、編號、科目、摘要、金額、制單／審核人
- 原始憑證附件為 **選用功能**，非正式歸檔與簽章流程
- 憑證至少保存 **5 年**、帳簿及報表至少 **10 年**（未結事項除外）
- 電子處理應依《商業使用電子方式處理會計資料辦法》規劃

### 明確不包含
- 稅務申報（營業稅、營所稅、扣繳、電子發票等）
- 完整 EAS 報表格式與附註揭露
- 正式電子簽章、SSO

### 身分與內控（教學限制）
- 示範帳號僅供課堂使用；正式環境請變更密碼並限制網路存取
- 操作身分應綁定登入 Session（已修正不可切換操作員選單）
- 審計日誌為應用層 + SQLite Trigger 防護，**非**對本機管理者絕對不可竄改

### 用語
- 文件中「GAAP」在本專案應理解為對 **EAS／商業會計處理準則** 之借鑒，非 US GAAP 合規證明
